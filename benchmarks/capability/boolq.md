# BoolQ

[Benchmark index](../README.md) | [Shared protocol](../protocol.md)

**Role:** principal task. **Coverage:** 2,000 inputs per condition.

## Input structure

- `question`
- `passage`
- `label`

## Output and measures

Output: yes/no answer.

Measures: accuracy.

## Construction and scope

The evaluated file contains 2,000 items from the training split.

This is the paper-specific evaluation panel, not an official held-out BoolQ test score. Unparseable responses count as incorrect.
