# Original stock windows

[Benchmark index](../README.md) | [Shared protocol](../protocol.md)

**Role:** principal task. **Coverage:** 2,074 inputs per condition.

## Input structure

- `asset/date identifier`
- `ordered price window`
- `window return`
- `volatility`

## Output and measures

Output: BUY; SELL; HOLD.

Measures: action distribution.

## Construction and scope

Construct overlapping windows from 2,102 asset/date records across seven assets in the source material.

This is a price-based next-action adaptation of source material, not a reproduction of the FinMem trading agent or a profitability benchmark.
