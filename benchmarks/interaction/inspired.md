# INSPIRED recommendations

[Benchmark index](../README.md) | [Shared protocol](../protocol.md)

**Role:** principal task. **Coverage:** 119 inputs per condition.

## Input structure

- `eligible dialogue prefix`
- `movie-recommendation context`

## Output and measures

Output: ACCEPT; REJECT; ASK_MORE.

Measures: next-action distribution.

## Construction and scope

Retain 119 eligible dialogue prefixes from 999 downloaded source dialogues.

This principal task asks for one next action given a supplied history. It is distinct from the authored sequential-feedback probes.
