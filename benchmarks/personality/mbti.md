# MBTI personality verification

[Benchmark index](../README.md) | [Shared protocol](../protocol.md)

**Role:** principal task. **Coverage:** 46 inputs per condition.

## Input structure

- `item/question`
- `two response options`
- `option-to-dimension/pole mapping`

## Output and measures

Output: one selected option.

Measures: pole-choice proportion by dimension.

## Construction and scope

The main T/F analysis uses 46 valid T/F questionnaire items. E/I, S/N and J/P checks are complementary dimension-specific analyses.

46 is the T/F item count, not the item count for every dimension. This is an operational check on model responses, not a human personality diagnosis. Questionnaire records are not released.
